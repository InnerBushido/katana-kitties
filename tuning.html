Committing it

Save writes src/tuning.json and Vite reloads the running game with it — no restart. When you like what you have:

git add src/tuning.json
git commit -m "Retune the Cross Slash"
git push

Only the numbers you actually moved are written, so the diff is the change. An empty {} is the shipped balance.
